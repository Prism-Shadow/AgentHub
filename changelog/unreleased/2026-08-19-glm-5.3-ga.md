# GLM-5.3 general availability

- **Date:** 2026-08-19
- **Type:** feature
- **Scope:** `registry`, `llmsdk_docs`, `tests`, `skills`

[中文版](2026-08-19-glm-5.3-ga.zh.md)

Z.AI launched the `glm-5.3` API, so the model moves off the pre-launch footing it shipped
on in [0.4.2](../0.4.2/2026-08-14-glm-5.3.md): the documentation snapshot, the registry
pricing, and the env-gated E2E model now come from the live product.

## What changed

- `llmsdk_docs/glm5_3/` was re-snapshotted as raw markdown from the official English
  documentation at docs.z.ai, replacing the pre-launch summary taken from
  docs.bigmodel.cn. The snapshot gained `chat-completion.md` (OpenAPI schema),
  `concept-param.md`, `migrate-to-glm-new.md`, `stream-tool.md`, and `thinking-mode.md`
  alongside the refreshed `glm-5.3.md` and `thinking.md`.
- The launched documentation confirms the thinking contract the client was written
  against: forced thinking (`thinking.type: "disabled"` errors) and `reasoning_effort`
  restricted to `low`/`high`/`max` with `max` as the default. `ThinkingLevel` mapping was
  left unchanged.
- `glm-5.3` replaced `glm-5.2` as the env-gated E2E model in `AVAILABLE_MODELS`: the
  official Z.AI entry, the `openai-chat` and `openai-responses` Z.AI protocol-client
  modes, and the OpenRouter entry, which moved to `z-ai/glm-5.3`. The SiliconFlow entry
  stayed on `zai-org/GLM-5.2`, which is the newest GLM that provider lists.
- The `ant-messages` Z.AI protocol-client mode stayed on `glm-5.2`. Z.AI's
  Anthropic-compatible gateway defaults to thinking disabled when a request carries no
  thinking config, and `glm-5.3` rejects that with `400` code `1210` ("This model always
  engages in thinking and cannot be disabled"). On that gateway `glm-5.3` answers only
  when `thinking_level` is set to `LOW`, `HIGH`, or `MAX`.
- The supported-model tables in `README.md` and both `skills/*/reference/models.md` were
  updated for the launch, adding the OpenRouter-hosted `z-ai/glm-5.3` id.

## Registry metadata

`glm-5.3` gained the official list price published at
https://docs.z.ai/guides/overview/pricing: $1.4 input, $0.26 cached input, and $4.4
output per million tokens - the same rates as `glm-5.2` and `glm-5.1`.

`z-ai/glm-5.3` was added for OpenRouter with a 1,048,576-token context window, text
input/output, and the same $1.4 / $0.26 / $4.4 pricing reported by
`GET https://openrouter.ai/api/v1/models`. The `z-ai/glm-5.2` OpenRouter pricing was
refreshed from the same source to $0.966 input, $0.1932 cached input, and $3.036 output.

# Gemini 3.7 generation support

- **Date:** 2026-08-13
- **Type:** feature
- **Scope:** `gemini3_7`, `gemini3_6`, `auto_client`, `registry`, `tests`
- **PR:** [#168](https://github.com/Prism-Shadow/agenthub/pull/168)

[中文版](2026-08-13-gemini-3.7.zh.md)

AgentHub now supports `gemini-3.7-flash`, Google's latest stable Flash model, on the official Gemini API and Vertex AI.

## Protocol findings

- The wire protocol is identical to the Gemini 3.6 generation: sampling parameters stay deprecated, model turn prefill stays disallowed, thought signatures replay unchanged, and thinking is configured with the `thinking_level` enum.
- The one model-visible change: `gemini-3.7-flash` accepts only `low`, `medium`, and `high` thinking levels, returning HTTP 400 "Thinking level MINIMAL is not supported for this model" for `minimal`.

## Implementation

- Because the protocol is identical, the shared client folder was renamed for the newest generation: `gemini3_6/` becomes `gemini3_7/` (`Gemini3_6Client` → `Gemini3_7Client`) in both languages, and it keeps serving `gemini-3.6-flash` and `gemini-3.5-flash-lite`. Routing accepts `gemini-3.7` ahead of the `gemini-3.6` and `gemini-3.5-flash-lite` aliases, which stay supported.
- The client now clamps thinking levels per model with the same mechanism the Gemini 3 client gained in the 2026-07-24 change: on `gemini-3.7-*` models the supported set is `low`/`medium`/`high`, so `ThinkingLevel.NONE` (mapped to Gemini `minimal`) degrades to `low`; the 3.6-generation models keep the full four-level set and are unaffected.
- `gemini-3.7-flash` replaces `gemini-3.6-flash` in the env-gated E2E model lists (official and Vertex providers) per the newest-version rule; the 3.6 models stay routed and supported.
- The client now round-trips the wire function-call id: a `tool_call` stores `function_call.id` as its `tool_call_id` (falling back to the name when the API sends none), the replayed `FunctionCall` carries that id back, and every `FunctionResponse` includes both the call id and the function name, as the generateContent API expects. The name is recovered from the matching `tool_call` earlier in the conversation; a history from before ids were stored carries the name as its `tool_call_id` and degrades to the previous name-only form.

## Registry metadata

`gemini-3.7-flash` is registered with text, image, video, and audio input, text output, a 1,048,576-token context window, and the official list price of $1.50 input, $7.50 output (thinking billed as output), and $0.15 context-cache read per million tokens — the same list price as `gemini-3.6-flash`. Google halves all three rates as a launch discount through 2026-12-31, which the registry's flat pricing does not model.

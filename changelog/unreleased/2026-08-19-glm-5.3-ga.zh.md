# GLM-5.3 正式上线

- **Date:** 2026-08-19
- **Type:** feature
- **Scope:** `registry`, `llmsdk_docs`, `tests`, `skills`

[English](2026-08-19-glm-5.3-ga.md)

Z.AI 已上线 `glm-5.3` API，因此该模型不再沿用 [0.4.2](../0.4.2/2026-08-14-glm-5.3.zh.md) 中的预上线状态：文档快照、注册表定价以及受环境变量控制的 E2E 模型均改为取自已上线的正式产品。

## 变更内容

- `llmsdk_docs/glm5_3/` 依据 docs.z.ai 上的官方英文文档重新抓取为原始 markdown，替换此前取自 docs.bigmodel.cn 的预上线摘要。除更新后的 `glm-5.3.md` 与 `thinking.md` 外，快照新增了 `chat-completion.md`（OpenAPI schema）、`concept-param.md`、`migrate-to-glm-new.md`、`stream-tool.md` 和 `thinking-mode.md`。
- 上线后的文档确认了此前实现所依据的思考契约：强制思考（`thinking.type: "disabled"` 会报错），且 `reasoning_effort` 限定为 `low`/`high`/`max`，默认值为 `max`。`ThinkingLevel` 的映射保持不变。
- 在 `AVAILABLE_MODELS` 中，`glm-5.3` 取代 `glm-5.2` 成为受环境变量控制的 E2E 模型：包括 Z.AI 官方条目、`openai-chat` 与 `openai-responses` 两种 Z.AI 协议客户端模式，以及改为 `z-ai/glm-5.3` 的 OpenRouter 条目。SiliconFlow 条目仍保留 `zai-org/GLM-5.2`，这是该提供方所列出的最新 GLM 版本。
- `ant-messages` 这一 Z.AI 协议客户端模式仍保留 `glm-5.2`。当请求未携带思考配置时，Z.AI 的 Anthropic 兼容网关默认关闭思考，而 `glm-5.3` 会以 `400` 错误码 `1210` 拒绝（"This model always engages in thinking and cannot be disabled"）。在该网关上，只有将 `thinking_level` 设为 `LOW`、`HIGH` 或 `MAX` 时 `glm-5.3` 才会正常应答。
- `README.md` 和两份 `skills/*/reference/models.md` 中的支持模型表按本次上线更新，并新增 OpenRouter 托管的 `z-ai/glm-5.3` 模型 id。

## 注册表元数据

`glm-5.3` 采用 https://docs.z.ai/guides/overview/pricing 公布的官方列表价：每百万 token 输入 $1.4、缓存输入 $0.26、输出 $4.4 —— 与 `glm-5.2`、`glm-5.1` 的费率相同。

为 OpenRouter 新增 `z-ai/glm-5.3` 条目，上下文窗口 1,048,576 token，文本输入/输出，定价同为 $1.4 / $0.26 / $4.4，取自 `GET https://openrouter.ai/api/v1/models`。`z-ai/glm-5.2` 的 OpenRouter 定价依据同一数据源刷新为：输入 $0.966、缓存输入 $0.1932、输出 $3.036。

# 注册表新增 Claude Opus 5，GPT-5.6 改用具体型号命名

- **Date:** 2026-08-19
- **Type:** feature
- **Scope:** `registry`, `skills`
- **PR:** [#180](https://github.com/Prism-Shadow/agenthub/pull/180)

[English](2026-08-19-opus-5-and-gpt-5.6-sol.md)

## 变更内容

- 注册表新增 `claude-opus-5`（Anthropic 官方 API），以及 OpenRouter 上的 `anthropic/claude-opus-5`。两者均通过既有的 `claude-5` 客户端路由，无需改动客户端。
- 官方 GPT-5.6 注册表条目由裸别名 `gpt-5.6` 改名为具体的 `gpt-5.6-sol`，与 OpenRouter 条目及 `gpt-5.6-terra`、`gpt-5.6-luna` 同级条目保持一致。裸写法 `gpt-5.6` 仍可路由到 GPT-5.6 客户端。
- `README.md` 的支持模型表和两段快速上手示例均改用 `gpt-5.6-sol`。
- 两份 `skills/*/reference/models.md` 补上了缺失的 GPT 5.6 行（官方与 OpenRouter），并在 Claude 5 行中于 `claude-fable-5` 之外列出 `claude-opus-5` 与 `claude-sonnet-5`。
- 三个 OpenRouter GPT-5.6 条目依据 live models API 重新定价：`openai/gpt-5.6-sol` 此前沿用的是 OpenAI 的列表价而非 OpenRouter 的价格，`openai/gpt-5.6-terra` 与 `openai/gpt-5.6-luna` 此前沿用的则是各自的 `:batch` 费率。

## 注册表元数据

`claude-opus-5` 的注册信息为：文本与图像输入、文本输出，以及 1,000,000 token 的上下文窗口。定价取自 https://platform.claude.com/docs/en/about-claude/pricing：每百万 token 输入 $5、缓存输入 $0.50（缓存命中价）、输出 $25；官方条目与 OpenRouter 条目采用相同费率，`GET https://openrouter.ai/api/v1/models` 报告的费率与之一致。

`gpt-5.6-sol` 沿用改名前条目已有的费率，并已对照 OpenAI 公布的定价确认：每百万 token 输入 $5、缓存输入 $0.50、输出 $30。

OpenRouter 的 GPT-5.6 定价现已与 `GET https://openrouter.ai/api/v1/models` 一致：`openai/gpt-5.6-sol` 为 $2.5 / $0.25 / $15，`openai/gpt-5.6-terra` 为 $2 / $0.20 / $12，`openai/gpt-5.6-luna` 为 $0.20 / $0.02 / $1.2（每百万 token 输入 / 缓存输入 / 输出）。

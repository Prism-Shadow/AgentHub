# 支持 Gemini 3.8 Flash

- **Date:** 2026-09-03
- **Type:** feature
- **Scope:** `gemini3_8`, `registry`, `claude5`, `ant_messages`, `glm5_3`
- **PR:** [#199](https://github.com/Prism-Shadow/agenthub/pull/199)

[English](2026-09-03-gemini-3.8-flash.md)

## 变更内容

- AgentHub 在官方 Gemini API 与 Vertex AI 上支持 `gemini-3.8-flash`：输入支持文本、图像、视频与音频，
  输出为文本，上下文窗口 1,048,576 token，输出上限 65,536 token。
- 其 wire 契约与 3.7 代完全一致，因此共享的客户端目录照例按最新一代重命名：两种语言中 `gemini3_7/`
  改为 `gemini3_8/`，`Gemini3_7Client` 改为 `Gemini3_8Client`。注册表中全部 Gemini 条目——文本、图像、
  TTS 与 embedding——的 client 均改为 `gemini-3.8`。
- 路由逻辑未变：分支仍按 `gemini-3` 前缀匹配，因此 `gemini-3.7`、`gemini-3.6` 与 `gemini-3` 仍是可用的
  `client_type` 写法，并会路由到重命名后的客户端。已有测试锁定这一点。
- 3.8 代与 3.7 一样对 `minimal` 思考等级返回 400，故并入该分支：`thinking_level: none` 收敛为 `low`，
  不再原样下发。
- 受环境变量控制的 E2E 模型列表（官方与 Vertex）中，`gemini-3.8-flash` 取代 `gemini-3.7-flash`。
- `llmsdk_docs/gemini3_8/` 收录该代的总览、模型规格与思考等级表；3.7、3.6 与 3 的思考等级表补入该模型，
  文档索引一并列出。

## 价格

- `gemini-3.8-flash` 按 Google 牌价登记：每百万 token 输入 $1.50、输出 $7.50、缓存输入 $0.15，
  与 `gemini-3.7-flash`、`gemini-3.6-flash` 已有的价格表相同。
- Google 至 2026-12-31 的首发折扣把三个模型的三档费率各砍一半，这一促销被有意不予记录：注册表负责
  目录价，套用在售促销是使用方的事。新增条目的注释说明了这一点。

## 配置行为

- `thinking_summary` 不再依赖 `thinking_level`。在 `claude5`、`ant_messages`、`deepseek_v4` 与
  `gpt5_6` 中，它原本嵌在思考等级分支内，单独传入时根本不会进入请求，而 `deepseek_v4` 无论如何都会
  丢弃它。上述客户端现在会独立下发该开关：Anthropic 协议用 `thinking.display`，Responses 协议用
  `reasoning.summary`。
- `thinking_summary: false` 在 Anthropic 协议客户端上落为 `thinking.display: "omitted"`，不再被当作
  未设置，与 Gemini 客户端一直下发的 `include_thoughts=False` 对齐。
- 5.2 之前的 GLM 各代也会收到收敛后的 `reasoning_effort`，不再在客户端丢弃；Z.AI、OpenRouter 与
  SiliconFlow 在这些模型上均接受该参数。
- 有三处维持原行为，因为改动后厂商会返回 400：Gemini 2.5 系列拒绝任何 `thinking_level` 取值，因此该
  参数对其继续省略（`include_thoughts` 仍照常下发）；Anthropic Messages API 拒绝在 disabled 思考块上
  附带 `display`，而 `thinking_level: none` 在该协议下选中的正是 disabled；`openai_responses` 也继续
  把摘要绑定在思考等级上，因为 OpenRouter 会把不带 effort 的 `reasoning` 对象理解为「关闭推理」，并在
  强制思考的模型上拒绝该请求。
